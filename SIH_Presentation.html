Core Algorithm

Proprietary Hybrid AI Matching Engine

📐 Mathematical Formulation

// 1. Multi-factor Raw Score

Score_raw = (0.30 * S_vector) + (0.70 * S_skill)

// 2. Non-linear Boosting Curve

Score_final = (Score_raw)^0.5 * 100

• 70% Skill Coverage: Evaluates direct intersection of mandatory tech skills.

• 30% Semantic NLP: TF-IDF vector similarity between profile aspirations & role context.

• Square Root Boost: Compresses middle scores (e.g. 0.50 ➔ 70.7%) to reward foundational competence.

1. NLP Text Vectorization

Combines career goals, skills, and industry preferences using TF-IDF vectorizer with English stop-word filtration.

2. High-Dimensional Cosine Similarity

Calculates angular alignment between candidate embedding vector and corporate job description vector.

3. Jaccard Skill Overlap Ratio

Computes exact set intersection: S_skill = |Student Skills ∩ Required Skills| / |Required Skills|.

4. Dynamic Ranking & Fallback Resilience

Instant real-time ranking with fallback heuristics ensuring 100% uptime even if LLM connectivity drops.

AI Mock Studio

AI Mock Interviewer with Real-Time Diagnostics

🎙️ Simulated Interview Session

  • 1. Targeted Role Configuration: Candidates select specific job roles (e.g. AI Product Analyst, Full Stack Dev).
  • 2. Behavioral & Technical Prompts: Live questions evaluating STAR structure, domain knowledge, and problem-solving.
  • 3. Real-Time Video/Audio Feedback: In-session evaluation of pace, confidence, tone, and keyword usage.

📊 4-Pillar Diagnostic Report

  • • Clarity & Articulation: Scores conciseness and speech structure.
  • • Keyword Proficiency: Measures accurate use of domain terminology.
  • • Behavioral Alignment: Validates STAR (Situation, Task, Action, Result) methodology.
  • • Actionable Next Steps: Provides targeted remediation resources for weaker areas.
